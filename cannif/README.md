# cannif
> Every magician needs a beautiful assistant!

Cannif is a web GUI for the [Annif toolkit](https://annif.org) using its REST API.  It is built using [Streamlit](https://streamlit.io).

### well, sort of

Because Streamlit apps are just regular Python scripts, cannif can also interact with a local copy of Annif directly, providing (almost?) full functionality.  Cannif provides:
- a sortable, searchable DataFrame-based list of projects
- an editor for backend parameters
- drag-and-drop training and evaluation (soon)
- split-ensemble training for memory reduction (soon)
